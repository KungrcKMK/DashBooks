# 🏪 DashBooks — สมุดบัญชีร้านค้า

แอปจดบัญชีสำหรับร้านเล็กๆ (ร้านก๋วยเตี๋ยว ร้านกาแฟ ร้านของชำ ฯลฯ) บันทึกขาย ลงทุน ถอนเงิน และลูกหนี้ แล้วสรุปกำไรให้อัตโนมัติ
ติดตั้งลงมือถือได้ ใช้ได้แม้ไม่มีเน็ต ไม่ต้องสมัคร ไม่มีเซิร์ฟเวอร์ ข้อมูลอยู่ในเครื่องของร้านเท่านั้น

**👉 เปิดใช้งาน: https://kungrckmk.github.io/DashBooks/**

## ✨ ความสามารถ

| หน้า | ทำอะไรได้ |
|---|---|
| 🏠 หน้าแรก | สรุปขาย / ลงทุน / กำไร / ถอน / เงินเหลือในร้าน / ลูกหนี้ รายวัน-สัปดาห์-เดือน, กราฟกำไร 7 วัน, ขายดี 3 อันดับ |
| ⚡ จดเร็ว | แป้นตัวเลขใหญ่ + ปุ่มลัดสินค้า แตะเดียวบันทึก มีปุ่มยกเลิก |
| ➕ บันทึก | จด 3 แบบ: 🛒 ขาย, 📦 ลงทุนซื้อของ, 🏧 ถอนไปใช้ |
| 📒 ลูกหนี้ | จดหนี้ รับชำระบางส่วน/เต็มจำนวน ส่งข้อความทวง |
| 🖼️ สรุป | รายงานรายเดือนเป็นรูปภาพ แชร์หรือคัดลอกได้ |
| ⚙️ ตั้งค่า | ชื่อร้าน + ไอคอน, สำรอง/กู้ข้อมูล (JSON), ส่งออก CSV |

- 🧮 ช่องจำนวนเงินพิมพ์สูตรได้ เช่น `45*3`, `120+35`, `10%`
- 📴 ใช้ออฟไลน์ได้หลังเปิดครั้งแรกตอนมีเน็ต
- 🔄 มีเวอร์ชันใหม่จะขึ้นแถบแจ้ง แตะเพื่ออัปเดต

## 📱 ติดตั้งลงมือถือ

- **iPhone** — เปิดลิงก์ใน Safari ➜ ปุ่มแชร์ ➜ "เพิ่มไปยังหน้าจอโฮม"
- **Android** — เปิดลิงก์ใน Chrome ➜ เมนู ⋮ ➜ "ติดตั้งแอป"

## 🔒 ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ใน `localStorage` ของเบราว์เซอร์ในเครื่องนั้นเท่านั้น ไม่ถูกส่งไปที่ไหน

- อัปเดตแอปหรือล้างแคช ➜ ข้อมูลไม่หาย
- "ล้างข้อมูลเว็บไซต์" หรือลบแอปออกจากหน้าจอโฮม (iPhone) ➜ **ข้อมูลหาย**
- ใช้ **⚙️ ตั้งค่า ➜ สำรองข้อมูล** เป็นประจำ และใช้ไฟล์นั้นย้ายข้อมูลไปเครื่องใหม่ได้

## 🛠️ สำหรับนักพัฒนา

เป็นเว็บแอปแบบไฟล์เดียว ไม่มี build step ไม่มี dependency

```
index.html              ตัวแอปทั้งหมด (HTML + CSS + JS)
sw.js                   Service Worker: ออฟไลน์ + อัปเดตอัตโนมัติ
manifest.json           ข้อมูลติดตั้งเป็นแอป (PWA)
icon-*.png              ไอคอน
Code.txt                คู่มือการอัปโหลดและแก้ปัญหา
```

**รันในเครื่อง**

```bash
python -m http.server 8000
```

แล้วเปิด http://localhost:8000 (Service Worker ทำงานเฉพาะบน `https:` จึงไม่ถูกลงทะเบียนตอนรันในเครื่อง)

**ปล่อยเวอร์ชันใหม่** — `git push` ขึ้น `main` แล้ว GitHub Pages จะอัปเดตภายในประมาณ 1 นาที
ถ้าแก้ไอคอน / `manifest.json` / `sw.js` หรืออยากให้ผู้ใช้เห็นแถบ "มีเวอร์ชันใหม่" ให้เพิ่มเลข `CACHE` ใน `sw.js` ด้วย (เช่น `shopbook-v10` ➜ `shopbook-v11`)
