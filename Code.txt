  index.html               ตัวแอปทั้งหมด
  sw.js                    Service Worker ➜ ทำให้เปิดตอนไม่มีเน็ตได้ + อัปเดตอัตโนมัติ
  manifest.json            ข้อมูลตอนติดตั้งเป็นแอป
  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png   ไอคอน

  เว็บจริง : https://kungrckmk.github.io/DashBooks/
  โค้ด     : https://github.com/KungrcKMK/DashBooks


🚀 อัปโหลดเวอร์ชันใหม่ 3 ขั้น

  1️⃣  แก้โค้ด
  2️⃣  ถ้าอยากให้ลูกค้าเห็นแถบ "🆕 มีเวอร์ชันใหม่" ➜ เปลี่ยน 'shopbook-v10' ใน sw.js
      เป็น v11, v12 ไปเรื่อยๆ (ห้ามลดเลข ห้ามใช้เลขซ้ำ)
  3️⃣  git add . ➜ git commit -m "..." ➜ git push
      ➜ รอประมาณ 1 นาที GitHub Pages ก็อัปเดตเสร็จ


⚠️ 4 เรื่องต้องรู้

  1) ต้องเปลี่ยนเลขเวอร์ชันใน sw.js ไหม?
     • แก้แค่ index.html      ➜ ไม่ต้องก็ได้ ลูกค้าได้หน้าใหม่เองตอนเปิดแอปครั้งถัดไป (แต่ไม่มีแถบแจ้ง)
     • แก้ไอคอน / manifest.json / sw.js ➜ ต้องเปลี่ยน ไม่งั้นเครื่องลูกค้ายังใช้ของเก่าในแคช
     • ไม่แน่ใจ               ➜ เปลี่ยนไปเลย ไม่มีผลเสีย
  2) ต้องเป็น https เท่านั้น (GitHub Pages / Netlify / Cloudflare Pages ใช้ได้ฟรีหมด)
     ➜ เปิดจากไฟล์ในเครื่อง file:// แอปใช้ได้ แต่ใช้ตอนไม่มีเน็ตไม่ได้ และไม่อัปเดตอัตโนมัติ
  3) ข้อมูลบัญชีไม่ได้อยู่ในแคชนี้ ➜ เก็บแยกใน localStorage
     ➜ อัปเดตแอปหรือล้างแคชไม่ทำให้ยอดขายหาย แต่ "ล้างข้อมูลเว็บไซต์" หายหมด
     ➜ ให้ลูกค้ากด "สำรองข้อมูล" ในหน้าตั้งค่าเป็นประจำ
  4) iPhone: แอปบนหน้าจอโฮมเก็บข้อมูลแยกกับ Safari
     ➜ จดใน Safari แล้วจะไม่เห็นในแอปบนหน้าจอโฮม (และกลับกัน)
     ➜ ใช้ผ่าน Safari เฉยๆ ไม่ได้เปิดนาน 7 วัน iOS อาจลบข้อมูลทิ้ง ➜ ควรเพิ่มไปยังหน้าจอโฮม


🔄 ลูกค้าได้อัปเดตยังไง

  • เปิดแอปตอนมีเน็ต ➜ ได้หน้าล่าสุดทันที
  • สลับกลับมาที่แอป ➜ แอปเช็กเวอร์ชันใหม่ ถ้ามีจะขึ้นแถบ "🆕 มีเวอร์ชันใหม่" ➜ แตะ "🔄 อัปเดต"
  • ไม่มีเน็ต ➜ ใช้เวอร์ชันล่าสุดที่เคยโหลดไว้ อัปเดตเองเมื่อกลับมามีเน็ต


🧯 แก้ปัญหาที่เจอบ่อย

  ❌ แก้โค้ดแล้วเปิดมายังหน้าเดิม
     ➜ เช็กว่า git push แล้ว และ GitHub Pages สร้างเสร็จแล้ว (แท็บ Actions ใน GitHub)
     ➜ ปิดแอปสนิทแล้วเปิดใหม่ตอนมีเน็ต
  ❌ ไอโฟนไม่อัปเดตสักที
     ➜ ปัดปิดแอปสนิท (ไม่ใช่แค่สลับแอป) แล้วเปิดใหม่ตอนมีเน็ต
     ➜ ยังไม่ได้อีก: กด "สำรองข้อมูล" ก่อน ➜ ลบไอคอนหน้าจอโฮม ➜ เพิ่มไปยังหน้าจอโฮมใหม่
        ➜ กด "กู้ข้อมูล" จากไฟล์ที่สำรองไว้
     ⚠️ ลบไอคอนหน้าจอโฮม = ข้อมูลในแอปนั้นหายด้วย ต้องสำรองก่อนเสมอ
  ❌ ไม่มีเน็ตแล้วเปิดไม่ได้
     ➜ ต้องเปิดตอนมีเน็ตอย่างน้อย 1 ครั้งก่อน เพื่อให้เก็บไฟล์ลงเครื่อง
